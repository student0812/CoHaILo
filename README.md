## 📖 Project Overview

CaHaILo is a comprehensive framework for detecting and analyzing hallucinations generated by large language models (LLMs) during code generation and comprehension tasks. The project employs Structural Probe technology to decode internal model representations, thereby revealing the model's understanding of code syntax structures and providing multidimensional hallucination detection.

### Core Features

- 🔍 **Probe Analysis**：Syntactic Comprehension Capabilities of Decoding Models Based on Neural Probe Technology
- 🤖 **Multi-model support**：Supports multiple pre-trained models including CodeBERT, GraphCodeBERT, CodeT5, and UniXcoder.
- 🎯 **Hallucination Detection**：Hallucination Detection for Mainstream LLMs (GPT, Claude, DeepSeek, Qwen)
- 📊 **Indicator Evaluation**：A Comprehensive Classification and Quantitative Evaluation System for Hallucination Types

### Installation Steps

#### 1. Clone Repository

```bash
git clone https://github.com/student0812/CaHaILo.git
cd CaHaILo
```

#### 2. Create a virtual environment

```bash
# Using conda (recommended)
conda create -n cahailo python=3.11
conda activate cahailo

#  or use venv
python -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate  # Windows
```

#### 3. Install dependencies

```bash
# Install prerequisites
pip install -r CoHaILo-main/requirements.txt

# Install Code-Repair module dependencies
pip install -r Code-Repair/requirements.txt
```

#### 4. Installation Tree-sitter

Tree-sitter is used for code syntax parsing:

```bash
cd CoHaILo-main/src/resource
mkdir -p grammars
cd grammars

# Download Language Grammar Library
git clone https://github.com/tree-sitter/tree-sitter-c.git
git clone https://github.com/tree-sitter/tree-sitter-python.git

# Compile the syntax library

python build_grammars.py
```

## 💻 User Guide

### 1. Data Preparation

The project is evaluated using the [https://github.com/student0812/CoHaILo/releases/tag/CoHaILo-dataset) dataset.
```bash
# Place the dataset in the specified directory
mkdir -p CoHaILo-main/src/resource/dataset/python
# Copy the dataset files to the above directory
# Preprocess the dataset
cd CoHaILo-main
python src/dataset_generator.py
```

2. Training the Probe Model

2.1 Rapid Training (Recommended)

```bash
cd CoHaILo-main
python run.py
```

2.2 Custom Training
```bash
python -m src.main \
    --do_train \
    --probe_name my_probe \
    --lang python \
    --first_step_model model_00.bin \
    --first_step_model_type codet5 \
    --rank 128 \
    --lr 1e-4 \
    --epochs 100 \
    --batch_size 32 \
    --seed 42
```
### 3. Testing and Evaluation

#### 3.1 Probe Model Testing

```bash
cd CoHaILo-main
python test.py \
    --probe_name my_probe \
    --first_step_model_type codet5 \
    --lang python
```

#### 3.2 Generating AST Representation

```bash
python customize_ast.py
```

#### 3.3 Conducting Interpretive Analysis

```bash
python do_explain.py
```

### 4. LLM Hallucination Detection
